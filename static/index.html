MoonTrace 使用方法与 Bilibili 登录说明
＋
01 / TRACE

粘贴并解析

将 Bilibili 视频链接或 BV 号粘贴到上方输入框， 点击「解析」。

02 / SELECT

选择内容

解析完成后，可选择视频画质、仅音频 M4A、 封面、字幕或弹幕 XML。

03 / AUTHORIZATION

需要更高画质？

未登录 Bilibili 时，部分高清画质可能不会出现。 请先在浏览器登录 Bilibili，然后在 MoonTrace 的 「下载设置 → Bilibili 登录态」中选择对应浏览器。

04 / ARCHIVE

下载并归档

选择需要的格式并开始下载。 Web 与 Telegram Bot 共用 MoonTrace 的下载设置。

◐
HIGH QUALITY ACCESS
如果只有低画质，先检查登录状态。

推荐使用一个单独的 Firefox 作为 MoonTrace 的 Bilibili 登录容器： 在 Firefox 登录 Bilibili，然后在下载设置里将浏览器选为 Firefox。

浏览器 Cookie

MoonTrace 保存的是浏览器与配置文件选择， 不保存你的 Bilibili 密码或 Cookie 内容。

Chrome / Edge 提示

如果浏览器正在占用 Cookie 数据库，读取登录状态有时会失败。 关闭对应浏览器后再试，或直接使用专门的 Firefox。

权限边界

MoonTrace 只使用当前账号已经拥有的访问权限， 不会绕过会员、付费或其他访问限制。

保存设置

设置会保存到项目里的 settings.json。

Bilibili 登录态

直接读取你本机浏览器的登录 Cookie；不会导出或保存 Cookie 内容。

未启用

先确保所选浏览器里已经登录 Bilibili。修改后重新解析视频即可。

使用边界与版权说明
＋
ACCESS / AUTHORIZATION
MoonTrace 只使用你当前账号已经拥有的访问权限。

MoonTrace 不提供 DRM、付费墙、会员权限或其他访问控制的绕过功能。 如果某项内容或画质需要特定账号权限，MoonTrace 只会在该账号本身有权访问时使用它。

01 / OWNERSHIP

优先处理你有权使用的内容

建议用于你自己上传的作品、已获作者授权的内容、 明确允许保存的内容，以及其他你合法拥有访问与使用权限的媒体。

02 / PLATFORM

同时遵守平台规则

使用 MoonTrace 时，仍需自行遵守所在地法律、 著作权规则以及对应平台的服务条款。

03 / REDISTRIBUTION

下载不等于可以重新传播

将他人的完整作品重新上传、公开传播、商用或批量搬运， 与个人保存是不同的行为，也可能带来更高的版权风险。

04 / LOCAL FIRST

本地、自托管、由用户控制

MoonTrace 默认在你的电脑上运行和保存文件。 浏览器登录态仅用于本机访问，不保存你的 Bilibili 密码。

本说明用于描述 MoonTrace 的设计边界，不构成针对任何具体情形的法律意见。
